# Security policy

This is a learning project and it is not maintained (see the README), so fixes
are best effort and may not come.

If you find a vulnerability, please report it privately through GitHub's
[private vulnerability reporting](https://github.com/Jesusw0w/price-tracker/security/advisories/new)
rather than in a public issue, especially anything touching the AWS deployment,
authentication (Cognito) or the MCP server.

If you deploy this yourself, you are responsible for your own AWS account:
review the IAM permissions and secrets in your stack before going live.
